# codex-test

Ancient Battle Simulator prototype in `pong.html`.

## Features
- Deployment phase with clear next-unit preview.
- Turn-based tactical battle with morale/routing and AI.
- Balanced leader roster (4 male, 4 female), including Tomyris and Zenobia.
- Defeat scene that generates an enemy taunt portrait.

## Run
Open `pong.html` in a browser.
